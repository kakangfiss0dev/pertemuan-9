Cara menjalankan (XAMPP):
1. Salin folder PBO09_CRUD_Array ke C:\xampp\htdocs
2. XAMPP Control Panel -> Start Apache saja (MySQL tidak perlu). PHP 8+.
3. Buka http://localhost/PBO09_CRUD_Array/            (CRUD Mahasiswa)
        http://localhost/PBO09_CRUD_Array/uji_oop.php (eksperimen OOP)
        http://localhost/PBO09_CRUD_Array/polimorfisme_hewan.php (latihan slide)
Data tersimpan di session browser, bukan database. Gunakan data fiktif.
